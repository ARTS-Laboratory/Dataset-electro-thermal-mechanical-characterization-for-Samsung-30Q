# Dataset 1
- Electro-thermal-deformation dataset.
- Each folder contains data from a different 30Q cell.
- Data was used in the first stage of training for PCML. 
- All tests were constant current
  - C-Rate is labeled in the file name
- Data categories collected was:
  - Time (s)
  - Current (A)
  - Voltage (V)
  - Power (W)
  - Cell Temperature (°C)
  - Hoop Strain 
  - Ambient Temperature (°C)
